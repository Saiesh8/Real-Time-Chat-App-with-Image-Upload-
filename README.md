💬 Real-Time Chat App with Image Upload
A real-time chat application that allows users to send text messages and images instantly using Socket.io and Node.js.

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript, Bootstrap

Backend: Node.js, Express.js

Real-Time Communication: Socket.io

File Uploads: Multer

Storage: Local file system (or cloud optional)

🧰 Features
💬 Real-Time Messaging: Send and receive messages instantly with WebSockets

🖼️ Image Upload: Send image files along with messages

👥 Multi-User Support: Join chat rooms with multiple users

🔒 Username Entry: Each user is identified by a unique username

🕓 Timestamps: Messages include time of sending

📱 Responsive UI: Works on mobile and desktop
